# Oral Multimodal Experiment

[中文版 (Chinese)](README.zh-CN.md)

Experiment code for pathology image + clinical text multimodal fusion in oral cancer grading (TCGA-HNSC).

Single-modality vs multimodal fusion comparison: pathology image features (UNI, ViT-L/16) + clinical text features (BiomedBERT), binary classification of Low-Grade (G1+G2) vs High-Grade (G3+G4). All results are based on 5-fold stratified cross-validation with per-model random-seed reset.

## Repository Layout

```
code/     # All experiment scripts (execution order below)
data/     # Data directory (not committed; generated by Step 1)
```

> Note: scripts resolve the data root as the parent of `code/` (i.e. `BASE_DIR/data/TCGA-HNSC/`). Keep the repository layout unchanged and create a `data/` directory under the repository root.

## Execution Order

Run the scripts in the following order; the output of each step feeds the next:

### Step 1: Data Download

```powershell
# Download TCGA-HNSC clinical data (506 cases)
python code\download_tcga.py

# Download pre-extracted UNI features (HuggingFace login required)
python code\download_pretrained_features.py
```

Output: `data/TCGA-HNSC/clinical_data.csv`, `data/TCGA-HNSC/pretrained_features/*.parquet`

### Step 2: Feature Extraction

```powershell
# BiomedBERT text feature extraction (506x768)
python code\extract_text_features.py

# Integrate UNI image features + text features + labels (499x1024 + 499x768)
python code\integrate_features.py
```

Output: `data/TCGA-HNSC/features/`, `data/TCGA-HNSC/integrated/`

### Step 3: Experiments

```powershell
# Main experiment: multimodal fusion (4 models x 5-fold CV, binary)
python code\multimodal_fusion_v2.py

# Text-only baseline
python code\text_baseline.py

# Modality dropout ablation
python code\modality_dropout_experiment.py

# DNDF vs MLP 4-class comparison
python code\dndf_experiment.py
```

Output: experiment logs and metrics printed to the console

### Step 4: Authenticity Audit

```powershell
# Real Grad-CAM heatmaps (replacing random noise)
python code\fix_real_gradcam.py

# Real attention weights (replacing hard-coded values)
python code\fix_real_attention.py

# Real DNDF parameters + mutual information computation
python code\fix_dndf_and_mi.py

# Export all experiment outputs as JSON
python code\save_experiment_outputs.py
```

Output: `data/TCGA-HNSC/experiment_outputs/`

### Step 5: Paper Figures

```powershell
# Fig 1-4: architecture / confusion matrices / performance comparison / ablation
python code\generate_figures.py
```

Output: figure output directory

### Step 6: Statistical Tests & Robustness (Final Protocol)

```powershell
# Main-table multi-seed robustness: full rerun over 3 seeds;
# seed=42 must reproduce the main table bit-identically
python code\main_multiseed.py

# Per-sample exact McNemar + Bonferroni (three nested cohorts)
python code\compute_mcnemar_exact.py
python code\compute_mcnemar_full_wide.py

# Leave-one-site-out (LOSO) and multi-seed learning curves
python code\leave_one_site_out.py
python code\learning_curves_multiseed.py
```

Output: `data/TCGA-HNSC/experiment_outputs/*.json` (the RNG is reset per model before each CV run; see each script's header comment for the protocol)

### Step 7: Protocol-Controlled Re-run (the results reported in the paper)

The manuscript's tables are produced by the `attention_v2_*` pipeline, which re-runs the whole comparison under nested cross-validation: early stopping is decided on an inner split of each training fold, and the held-out fold is touched only to compute the reported metrics. Run in this order:

```powershell
# 7a. Age units: render TCGA age_at_diagnosis (recorded in days) as whole years
python code\fix_age_units.py

# 7b. Feature bundle: token-level text embeddings + patch sequences
#     (writes data/TCGA-HNSC/attention_v2/; the .npz payloads are ~96 MB and not committed)
python code\prep_attention_v2.py

# 7c. Main grid: 3 cohorts x 5 configurations x 3 seeds x 5 folds
python code\attention_v2_experiments.py                               # full grid
python code\attention_v2_experiments.py --cohort strict --seeds 42    # smoke test

# 7d. Text ablations, cross-modality MI, leave-one-group-out, modality dropout
python code\attention_v2_aux.py
python code\attention_v2_loso_moddrop.py

# 7e. Representation-matched controls, structured baseline, matched MI, skip-path ablation
python code\attention_v2_rep_match.py
python code\attention_v2_structured_baseline.py
python code\attention_v2_mi_matched.py
python code\attention_v2_skip_ablation.py

# 7f. Per-sample McNemar, all-metric paired bootstrap, table bodies
python code\attention_v2_analysis.py
python code\attention_v2_tables.py

# 7g. Figures 1 and 4
python code\fig1_regenerate.py
python code\fig4_regenerate.py
```

Output: `data/TCGA-HNSC/experiment_outputs/attention_v2_*.json`. Every file stores per-fold metrics **and** per-sample out-of-fold predictions and probabilities, so the exact McNemar tests, the paired bootstrap intervals and the PR-AUC values can be recomputed without retraining.

**Environment used for the reported numbers**: `torch 2.12.0+cu126` on an NVIDIA RTX 4060, with `cudnn.deterministic = True` and the cuDNN autotuner disabled. BiomedBERT feature extraction runs on CPU. The seed is reset before every model's cross-validation loop, and one seed determines both the fold partition and the initialization (see the manuscript's Section 3.7 for why this makes the seed-to-seed spread an upper bound on initialization variance).

## Zero-Training Replay

The archived patient-level JSON under `data/TCGA-HNSC/experiment_outputs/` supports replay without retraining:

```powershell
python code\attention_v2_rederive.py
python code\attention_v2_tables.py
```

`attention_v2_rederive.py` re-derives the nested splits from `data/TCGA-HNSC/attention_v2/cohort_index.json` and recomputes all 45 (cohort, arm, seed) records / 225 folds, checking OOF lengths, probability bounds, `pred == argmax(prob)`, five-fold coverage, inner fit/selection disjointness, and three-seed means. Expected output: no failures, maximum metric delta 0.0, and strict-subset average precision 0.29284 (text-only) and 0.27111 (true cross-attention).

The 233-patient follow-up table is replayed separately from its archived run and labels:

```powershell
python code\replay_grade_followup.py --run <archived-run-directory> --labels <patient_join.csv>
```

The run directory and labels are held in the research archive; `results/main-grade-improvement-2026-11-09-v1/REPRODUCE.md` lists the required layout. The no-diagnosis preregistration is retained at `paper/prereg_nodx_fourcell.md`.

Feature arrays (`text_tokens.npz`, `img_patches.npz`), patch/UNI arrays and model weights are not committed. Retraining requires the request bundle described in `code/README.md`; this repository supports archive verification and zero-training replay, not public raw-source reconstruction.
