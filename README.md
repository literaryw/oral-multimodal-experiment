# Oral Multimodal Experiment

[中文版 (Chinese)](README.zh-CN.md)

Experiment code for pathology image + clinical text multimodal fusion in oral cancer grading (TCGA-HNSC).

Single-modality vs multimodal fusion comparison: pathology image features (UNI, ViT-L/16) + clinical text features (BiomedBERT), binary classification of Low-Grade (G1+G2) vs High-Grade (G3+G4). All results are based on 5-fold stratified cross-validation with per-model random-seed reset.

## Repository Layout

```
code/     # All experiment scripts (execution order below)
data/     # Data directory (not committed; generated by Step 1)
```

> Note: scripts resolve the data root as the parent of `code/` (i.e. `BASE_DIR/data/TCGA-HNSC/`). Keep the repository layout unchanged and create a `data/` directory under the repository root.

## Environment Setup

```powershell
conda create -n tcga-oscc python=3.12 -y
conda activate tcga-oscc
pip install -r code\requirements_full.txt
```

See `code/environment.md` for details.

## Execution Order

Run the scripts in the following order; the output of each step feeds the next:

### Step 1: Data Download

```powershell
# Download TCGA-HNSC clinical data (506 cases)
python code\download_tcga.py

# Download pre-extracted UNI features (HuggingFace login required)
python code\download_pretrained_features.py
```

Output: `data/TCGA-HNSC/clinical_data.csv`, `data/TCGA-HNSC/pretrained_features/*.parquet`

### Step 2: Feature Extraction

```powershell
# BiomedBERT text feature extraction (506x768)
python code\extract_text_features.py

# Integrate UNI image features + text features + labels (499x1024 + 499x768)
python code\integrate_features.py
```

Output: `data/TCGA-HNSC/features/`, `data/TCGA-HNSC/integrated/`

### Step 3: Experiments

```powershell
# Main experiment: multimodal fusion (4 models x 5-fold CV, binary)
python code\multimodal_fusion_v2.py

# Text-only baseline
python code\text_baseline.py

# Modality dropout ablation
python code\modality_dropout_experiment.py

# DNDF vs MLP 4-class comparison
python code\dndf_experiment.py
```

Output: experiment logs and metrics printed to the console

### Step 4: Authenticity Audit

```powershell
# Real Grad-CAM heatmaps (replacing random noise)
python code\fix_real_gradcam.py

# Real attention weights (replacing hard-coded values)
python code\fix_real_attention.py

# Real DNDF parameters + mutual information computation
python code\fix_dndf_and_mi.py

# Export all experiment outputs as JSON
python code\save_experiment_outputs.py
```

Output: `data/TCGA-HNSC/experiment_outputs/`

### Step 5: Paper Figures

```powershell
# Fig 1-4: architecture / confusion matrices / performance comparison / ablation
python code\generate_figures.py
```

Output: figure output directory

### Step 6: Statistical Tests & Robustness (Final Protocol)

```powershell
# Main-table multi-seed robustness: full rerun over 3 seeds;
# seed=42 must reproduce the main table bit-identically
python code\main_multiseed.py

# Per-sample exact McNemar + Bonferroni (three nested cohorts)
python code\compute_mcnemar_exact.py
python code\compute_mcnemar_full_wide.py

# Leave-one-site-out (LOSO) and multi-seed learning curves
python code\leave_one_site_out.py
python code\learning_curves_multiseed.py
```

Output: `data/TCGA-HNSC/experiment_outputs/*.json` (the RNG is reset per model before each CV run; see each script's header comment for the protocol)
